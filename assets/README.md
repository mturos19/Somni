# Screenshots

The main README expects these five files. Capture them at a phone-ish width
(around 430 x 900) or a narrow desktop window — the app is built for one hand in
the dark, and wide shots make it look emptier than it is.

| File | What to capture |
|---|---|
| `main_screen.png` | The story builder. Fill in a name, set the age dial, choose a theme, and select a few element chips so the counters read `2/2` and the rest are dimmed. |
| `writing_screen.png` | The waiting overlay, part-way through — the progress bar somewhere mid-fill with a percentage under it. |
| `reader_cover.png` | A story's cover: title, dedication, "Tonight's story" above it. |
| `reader_screen.png` | A page mid-narration, with one word lit in the accent colour. Pause on a good word. |
| `voice_screen.png` | The voice studio, with at least one passage recorded so the runtime band and the Steady/Natural/Lively control are both visible. |

Two of them are worth taking on different themes — Blossom and Voyager are the
furthest apart — since the theme is a selling point and a single palette hides it.
